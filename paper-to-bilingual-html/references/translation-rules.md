# Translation Rules

## Fidelity

1. 处理全文,不删减、不概括、不跳段、不改写原意。
2. 保留标题、作者信息、摘要、正文、图表标题、表格文字、公式相关说明、脚注、参考文献、附录等全部可读内容。
3. 保持原文结构与顺序,严格对应原始章节、标题、编号和段落层级。
4. 保留所有引文编号、公式编号、图表编号、脚注编号和参考文献编号原样。
5. 保留变量名、单位、符号、大小写和专有缩写,不要擅自中文化或重命名。

## References Stay Original

1. 参考文献(References / Bibliography)整块保持英文原状:完整列出每一条,不逐条翻译。
2. 不做任何"伪翻译"处理:不把 "et al." 改成"等",不中文化会议名、期刊名、书名。
3. 章节标题可以双语(如 `References` / `参考文献`),但条目本身只出现原文一次(通栏单栏,不再分中英两列)。
4. 致谢、版权与许可信息按普通内容正常翻译;它们不属于参考文献块。

## Translation Style

1. 译文优先保证忠实、完整、通顺,风格偏学术表达。
2. 首次出现的重要专业术语,可用"中文(English)"标注;之后保持术语一致。
3. 不要为了中文流畅而删掉限定条件、程度副词、逻辑转折或不确定性表述。
4. 遇到多义术语时,选择最贴合上下文的译法并保持全文一致;不要在译文中替作者做理论延伸。
5. 人名、机构名、产品名、模型名保留原文,不音译。

## Model-authored Translation Quality Gate

1. 最终译文必须由当前执行模型在理解完整段落及相邻语境后直接产出或逐句重写。通用机器翻译只能提供草稿,不能直接成为交付译文。
2. 每个可翻译单元都必须逐一校订;术语表替换、批量字符串替换或抽样检查不等同于校订。
3. 校订时同时检查:
   - 主语、谓语、宾语及修饰关系完整,没有机器翻译式残句或错误搭配。
   - 转折、因果、条件、范围、程度和不确定性与原文一致。
   - 专业术语符合论文语境并在全文保持一致。
   - 数值、引文、模型名、数据集名、变量和代码标识符保持原样。
   - 中文可以独立通顺阅读,但不通过增译改变作者论断。
4. 完成全文后,重新通读所有中文段落,清除生硬直译、术语漂移、机械替换痕迹及异常中英文混排。只有全部单元通过才可交付。
5. 内容过长时分批继续由模型翻译和校订;长度不是降级为未经复核机器翻译的理由。

## Tables, Figures, Equations

1. 表格优先转写为 HTML 表格(见 output-format.md);结构无法可靠还原时,插入表格截图并保留全部可读文字,显式说明"表格结构部分丢失,以下保留全部可读文字内容"。
2. 图题、表题按原位置以双语文字行呈现;图片文件本身不含 caption(截图时排除)。
3. 公式本体、符号和变量名保持原样;只翻译可翻译的说明文字。
4. 如果正文中有 "where x denotes ..." 一类公式说明,按普通段落完整处理。

## OCR and Ambiguity

1. 遇到 OCR 错误、扫描模糊、断句异常、错列、断词、乱码或歧义时,标注 `[原文疑似识别错误]`。
2. 不要根据上下文自信补齐缺字、缺词或缺行。
3. 怀疑版面串读(双栏错接)时,先按栏恢复阅读顺序再翻译;无法可靠恢复时向用户说明。

## No Extras

1. 默认不输出难点解析、学习建议、背景注释或主观评论。
2. 用户明确要求加难点解析时,聚焦长难句结构、从句关系、指代、术语译法与易误译点,放在对应双语行之后,不混入译文。
